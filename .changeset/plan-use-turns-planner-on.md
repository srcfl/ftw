"Use the plan" on the Plan tab now turns the planner on when it is off. It saves the same setting as Settings → Planner → Enabled, restarts FTW so the planner starts, hands the house to the plan and shows the plan when the box has one, about 8 s later on a test box. If prices or a battery are missing, the card says so where the button is. The planning style, battery export and Manual… wait for the first plan, and a home without a battery is no longer told about a battery. While FTW still learns the home, the plan's forecast says so. A box that never sold from the battery no longer asks whether selling may continue: a new box stores "not allowed", and turning the planner on from off records that answer for a box that stored "not checked". A box that sold through active arbitrage before its upgrade is still asked.
