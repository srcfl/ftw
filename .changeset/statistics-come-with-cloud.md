Anonymous statistics are part of FTW Cloud and nothing else. With FTW Cloud on, the box sends the hourly statistics and the two daily reports as before. Without FTW Cloud it sends none, whatever an earlier release stored, and a statistics-only link from an earlier release ends. The "Share anonymous statistics" switch is gone; Settings → FTW app → Anonymous statistics says which case holds. Accepting the terms when you pair, on the box page, in the app or in the web app, is enough: the box no longer asks again, and the Overview no longer prompts for them. An assistant's access now lasts 90 days unless you pick another length, on the box page and for invitations.
