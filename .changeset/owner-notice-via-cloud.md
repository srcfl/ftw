Pairing a phone no longer leaves a failed "A new owner" notification when FTW Cloud took it. FTW Cloud sends that notice to the owners' phones, but the notification history only counted the box's own channels. On a new box those have nobody to send to yet, so the row said "failed: no publisher installed" and the bell showed a red count. The history now shows the notice FTW Cloud holds as "queued", since the box cannot see it leave, and the bell stays clear. With FTW Cloud off, no notice is queued there. When no channel had anyone to send to, the row says "no phone or service to send to" instead of the wrong "no publisher installed".
