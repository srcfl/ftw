The overview names each configured device that does not answer, with what Core knows about it and a link to its settings. LIVE is green only while every device answers, graded as the apps grade it; `/api/status` now carries each driver's `src_state` and `last_ok_age_ms`. A device on a wrong port no longer leaves a green LIVE beside empty circles. A driver that only reads a car (`vehicle_only`) counts only when it reports an error, so a car away from home does not dim LIVE. When Core prices by an area nobody chose, the price card says so in one line that opens Settings → Price. "Unknown" energy shows in a neutral colour. The savings card names its baseline, "no solar or battery", since that number includes what the panels bring. More → Get help says to ask in the FTW Discord with the file.
