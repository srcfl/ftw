The EV charger picker reuses your saved Easee or Zaptec password only for the provider's own server or the address you saved; any other address must be given the password again. The house password can no longer be turned on for the first time through the app; that is still done on the box. With the house password on, the OCPP charger list, which shows charger serials and RFID card tags, needs the password like the other Settings reads. Home Assistant number commands that are not a finite number are ignored and logged instead of being saved. A Home Assistant bridge that fails to connect at start now stops retrying instead of connecting later in a half-working state.
